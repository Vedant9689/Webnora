## ✨ Features

- ⚡ **Lightning Fast & Lightweight**: Pure semantic HTML5, modern CSS3 (custom design system tokens), and vanilla JavaScript with zero framework overhead.
- 💰 **Transparent Service Pricing Packages**: Complete pricing tiers with deliverables, turnaround times, and dual-currency switcher (₹ INR / $ USD).
- 🧮 **Interactive Project Cost Calculator**: Dynamic slider and add-on selector allowing prospective clients to estimate project costs and dispatch scopes directly via email.
- 💼 **Case Studies & Proof of Work**: Filterable project showcases with before/after ROI metrics and interactive case study modals.
- 🌓 **Obsidian Dark & Clean Studio Light Themes**: Smooth theme switcher with local storage persistence.
- 📱 **100% Mobile Responsive**: Mobile navigation drawer, fluid typography, and touch-optimized controls.
- 📬 **Direct Lead Capture**: Comprehensive project inquiry form and contact routing to `contacttovedant5@gmail.com`.

## 🛠️ How to Run Locally

### Option 1: Open Directly in Browser
Simply double-click `index.html` to open it in Google Chrome, Edge, Safari, or Firefox.

### Option 2: Run with Local Web Server
```bash
# Using npx serve
npx serve .

# Or using Python 3
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🚀 How to Upload to GitHub

Follow these steps to upload this project to your GitHub account:

### 1. Initialize Git Repository
Open your terminal inside this project folder:
```bash
git init
git add .
git commit -m "Initial commit: VB Portfolio and Client Acquisition Website"
```

### 2. Create a Repository on GitHub
1. Go to [GitHub](https://github.com/new) and create a new repository (e.g., `vb-portfolio` or `portfolio`).
2. Do **not** initialize it with a README (since we already have one).

### 3. Connect and Push
```bash
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/vb-portfolio.git
git push -u origin main
```

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Free)
1. Go to your GitHub repository **Settings** $\rightarrow$ **Pages**.
2. Under **Branch**, select `main` and root `/` folder, then click **Save**.
3. Your site will be live at `https://YOUR_GITHUB_USERNAME.github.io/vb-portfolio/` in seconds!

### 2. Vercel / Netlify (Free & Recommended)
- Import your repository on [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
- Click **Deploy** (zero configuration needed for static HTML/CSS/JS).
